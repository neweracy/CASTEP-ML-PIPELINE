# Project Structure

Complete overview of files and directories in the DFT-ML Pipeline project.

## 📁 Core Directories

### `ML_Data/`
DFT calculation outputs (CASTEP files)
- `*.castep` - Main CASTEP output files with energies
- `*.geom` - Geometry optimization trajectories  
- `*.bands` - Electronic band structure data
- `*.cst_esp` - Electrostatic potential data
- Other auxiliary files (`*.trjaux`, `*.kptaux`, etc.)

### `STRUCTURES/`
Input structure files for DFT calculations

### `Ti_BASE_STRUCTURE/` & `Al_BASE_STRUCTURE/`
Reference crystal structures for pure elements

### `models/` (generated)
Trained ML models
- `gpr_model.pkl` - Serialized Gaussian Process model

### `.venv/`
Python virtual environment (uv-managed)
- Not tracked in git

---

## 🐍 Python Scripts

### `parse_castep.py`
**Purpose**: Extract DFT data and calculate formation energies

**Inputs**: `./ML_Data/*.castep` files  
**Outputs**: `alloy_ml_dataset.csv`

**What it does**:
1. Parses CASTEP output files
2. Extracts final energies and compositions
3. Calculates formation energy per atom
4. Exports clean CSV for ML

**Usage**:
```bash
uv run python parse_castep.py
# or
make run
```

---

### `train_ml.py`
**Purpose**: Train ML model and generate predictions

**Inputs**: `alloy_ml_dataset.csv`  
**Outputs**: 
- `formation_energy_curve.png` - Visualization
- `models/gpr_model.pkl` - Trained model (optional)
- `predictions.csv` - Predictions with uncertainties (optional)

**What it does**:
1. Loads DFT dataset
2. Trains Gaussian Process Regressor
3. Evaluates model (R², MAE, RMSE, CV)
4. Generates smooth predictions across composition range
5. Plots results with uncertainty bands

**Usage**:
```bash
# Basic (plot only)
uv run python train_ml.py

# Save everything
uv run python train_ml.py --save-model --save-predictions

# With make
make train
```

---

### `BatchRun.py`
**Purpose**: Materials Studio batch processing script
- Automates running multiple CASTEP calculations

## 📊 Generated Data Files

### `alloy_ml_dataset.csv`
**Generated by**: `parse_castep.py`

**Columns**:
- `Structure` - Identifier (e.g., Ti12Al4)
- `Total_Atoms` - Cell size
- `n_Ti`, `n_Al` - Atom counts
- `Atomic_Fraction_Al` - Al concentration (0-1)
- `Total_Energy_eV` - DFT total energy
- `Formation_Energy_eV_per_atom` - Target for ML

---

### `predictions.csv`
**Generated by**: `train_ml.py --save-predictions`

**Columns**:
- `Atomic_Fraction_Al` - Composition point
- `Predicted_Formation_Energy_eV_per_atom` - GPR prediction
- `Uncertainty_eV_per_atom` - Standard deviation (σ)
- `Lower_95CI`, `Upper_95CI` - 95% confidence bounds

---

### `formation_energy_curve.png`
**Generated by**: `train_ml.py`

**Content**:
- DFT data points (red scatter)
- GPR prediction curve (blue line)
- 95% confidence interval (light blue band)
- Professional formatting (300 DPI)

**See**: [GRAPH_GUIDE.md](GRAPH_GUIDE.md) for detailed interpretation

## ⚙️ Configuration Files

### `pyproject.toml`
Python project configuration (PEP 518)
- Dependencies (pandas, numpy, scikit-learn, etc.)
- Dev dependencies (jupyter, pytest, black, ruff)
- Tool settings (Black, Ruff)

### `uv.lock`
Dependency lock file for reproducible environments

### `.python-version`
Specifies Python 3.9

### `.gitignore`
Excludes generated files, outputs, and environments

### `Makefile`
Task automation shortcuts

**Commands**:
```bash
make help          # Show available commands
make install       # Install dependencies
make run           # Parse CASTEP files
make train         # Train ML model
make format        # Format code
make lint          # Lint code
make clean         # Remove generated files
```

## 🔗 File Dependencies

**Workflow**:
1. Run DFT calculations → `ML_Data/*.castep`
2. Parse outputs → `alloy_ml_dataset.csv`
3. Train ML model → graphs, models, predictions

```
ML_Data/*.castep
    ↓
parse_castep.py
    ↓
alloy_ml_dataset.csv
    ↓
train_ml.py
    ↓
├── formation_energy_curve.png
├── models/gpr_model.pkl
└── predictions.csv
```
